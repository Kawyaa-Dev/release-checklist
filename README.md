# Release Checklist Tool

A modern web app to manage software release checklists.

## Stack

- **Frontend:** React + Vite
- **Backend:** Node.js + Apollo GraphQL
- **Database:** PostgreSQL (Prisma ORM)
- **Container:** Docker + Docker Compose
- **Deployment:** Vercel (UI) + Render (API) + Neon (DB)
